# Контракт снимка контрагента 1.0.0

Схемы `headers.schema.json` и `body.schema.json` описывают входящие `contragent_created` и `contragent_updated`. Каталог лежит рядом с исходниками расширения и не является объектом метаданных 1С.

Проверка примеров:

```text
python validate_fixtures.py
```

Файл схемы принимает любую minor-версию major 1 (`1.x.y`). Список разрешённых minor остаётся настройкой контура. Числовой `id` в схеме не ограничен сверху: разрядность хранения закрепится после ответа портала о диапазоне.

В примерах ТЗ поле `timestamp-ms` было десятизначным и содержало секунды. В fixtures к тем же значениям дописаны три нуля, семантика полей не менялась. `1789707183` стал `1789707183000`.

## Каталог кодов

Публиковать можно только эти коды. Условие без более точного кода записывается как `INTERNAL_ERROR`.

- `REQUIRED_FIELD_MISSING` — нет обязательного поля или строка `name` пустая либо состоит из пробелов. Путь — само поле.
- `INVALID_FORMAT` — тип, UUID, перечисление, десятизначный `timestamp-ms` или иной формат не совпали со схемой. Путь — само поле.
- `UNSUPPORTED_VERSION` — major в `version` не входит в настройку контура. Путь `null`. Этот файл схемы описывает только major 1 и сам по себе не выбирается для чужого major.
- `REFERENCE_NOT_FOUND` — нет элемента 1С по ссылке, кроме головного контрагента. Путь — поле ссылки, например `contracts[0].organization.uid`.
- `HEAD_CONTRAGENT_NOT_FOUND` — голова не найдена после трёх попыток. Путь `head_contragent`.
- `DUPLICATE_CONFLICT` — идентификаторы указывают на разные или несколько карточек, либо пара `organization.id` и `organization.uid` не согласована. Путь `null` либо ключевое поле.
- `INTERNAL_ERROR` — технический сбой записи или удаления. Путь `null`, если ошибка не привязана к полю.

Схема входящего сообщения напрямую отличает только `REQUIRED_FIELD_MISSING` и `INVALID_FORMAT`. Остальные пять кодов выставляет адаптер после публикации Started.

## Путь JSON

Путь в `messages[].path` строится от тела сообщения:

- поле: `name`, `uid`, `timestamp-ms`;
- вложенное поле: `head_contragent.id`, `contracts[0].organization.uid`;
- элемент коллекции: `addresses[0].type`, `bank_accounts[0].id`, `contracts[0]`.

Индекс начинается с нуля. Для заголовка путь равен имени заголовка. Если ошибка не относится к полю, путь равен `null`.
