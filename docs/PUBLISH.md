# Публикация поставки проекта

Репозиторий проекта — https://github.com/DmitrySkrypkin/1c-kafka-counterparties. В нём размещаются расширения РФ и КЗ, контракты, документация и готовые CFE.

Перед публикацией выгрузите CFE и XML расширений из проверенных dev-баз с указанием имени расширения ИнтеграцияApacheKafka. Соберите cfe-rf, cfe-kz, dist и docs в отдельном клоне проекта. Дополните выгрузку каталогами contract из исходников. Обновите README, описание изменений, инструкции и протокол проверок. Контрольные суммы CFE храните в dist/SHA256SUMS.txt.

Перед commit проверьте состав diff, ссылки документации, примеры сообщений и отсутствие файлов подключения или учётных данных. Прогресс приёмки отражается в протоколе. Если существенные проверки остаются открытыми, поставка получает статус prerelease.

После commit и push создайте тег поставки и GitHub Release с двумя CFE, SHA256SUMS.txt и инструкциями Word. Проверьте опубликованный commit и скачанные контрольные суммы. Раздел About содержит описание обмена контрагентами, номенклатурой и счетами для РФ и КЗ.
