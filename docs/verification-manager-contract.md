# Проверка поставки менеджера и договора

Поставка от 24.11.2026 проверена на dev-базах БП РФ и БП КЗ, платформа 8.3.27.1936. Версия метаданных расширения — 1.2.0.

В каждой базе прошли проверка модулей, применимости расширения, целостности конфигурации и обновление структуры БД. По 19 сценариев и 58 утверждений прошли, тестовые документы и служебные записи очищены. Проверены создание счёта, выбор второго договора, договор только по id, смена менеджера, пропуск и пустые обязательные поля, сохранность существующего документа при ошибке, неизвестный менеджер, договор другой организации, ожидание и появление договора, истечение окна и компактное удаление. Исходящий сериализатор возвращает UID, договор и учётный номер.

Поле «UID менеджера портала» открыто в веб-клиентах обеих баз под администратором. Отдельный вход пользователем без полных прав и нагрузочная проверка одновременного назначения UID не выполнялись. Ограничение прав защищено серверным обработчиком; уникальность проверяется под общей исключительной блокировкой справочника пользователей.

Для каждого контура 20 примеров сообщений проходят схемы. Определения JSON Schema проверены. Входящий полный снимок портала использует body.portal.schema.json, исходящий снимок 1С — body.schema.json, сокращённое удаление — body.soft-delete.schema.json.

Полная приёмка открыта. Терминальные статусы проверены в локальной очереди 1С, сквозная доставка через отдельный Kafka-контур требует подтверждения. Проверка адаптеров BSL сообщает существующие замечания анализа транзакций. Валидатор XML не имел catalog.xsd; инструменты check_1c_code и review_1c_code в сессии отсутствовали. Модули пользователей и формы прошли синтаксическую проверку, обе формы прошли структурную проверку.

Исходники cfe-rf и cfe-kz выгружены штатным DumpConfigToFiles, CFE — штатным DumpCfg из тех же dev-баз после проверки. Схемы контрактов и примеры добавлены отдельно. SHA256 файлов CFE указан в dist/SHA256SUMS.txt. Перед включением поставки заполните UID менеджеров в карточках пользователей принимающей базы.
