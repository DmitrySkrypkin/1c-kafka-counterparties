# Release notes — ИнтеграцияApacheKafka 1.0.0

**Дата:** 1 ноября 2026  
**Тема релиза:** входящий обмен полным снимком контрагента (ТЗ) для контуров РФ и КЗ

## Highlights

- Контракт Kafka `contragents` / `contragents.exchange`, schema `1.0.0`
- Две собираемые поставки расширения: РФ и КЗ
- Прямой consumer через Simple Kafka 1C (без REST)
- Inbox → Started (Outbox) → бизнес-снимок → Completed/Failed
- Идемпотентность, retry головы (до 3 попыток), каталог из 7 кодов ошибок
- Пакет документации: концепция, задание порталу, инструкции администратора (md + docx)

## Patch 01.11.2026 — soft-delete детей снимка

Отсутствующие в полном снимке `bank_accounts` и `contracts` получают `ПометкаУдаления` вместо физического `Удалить()`. Повторное появление в снимке снимает пометку. Ссылочный запрет платформы больше не откатывает sync по занятому счёту/договору.

## Что вошло

### Транспорт

- Фоновый lifecycle consumer (`Запустить` / `Остановить` / `Состояние`)
- Ручная фиксация offset после записи Inbox
- Маршрутизация `organization-id` через регистр (не GUID организации)
- Журнал этапов, карантин битых envelope, маскирование секретов в диагностике

### Бизнес (контрагенты)

- Идентичность: внешний `id` → `uid` → `reg_number + kpp`
- Полный снимок с soft-delete отсутствующих счетов и договоров (`ПометкаУдаления`)
- Адаптер РФ: `KFK_АдаптерКонтрагентовРФСервер`
- Адаптер КЗ: `KFK_АдаптерКонтрагентовКЗСервер`

### Эксплуатация

- Роли `KFK_СервисОбмена`, `KFK_ДиагностикаОбмена`
- Секреты из env / файла / БСП-хранилища
- Replay failed, метрики порогов, регламент очистки retention
- Автозапуск через `KFK_ЗаданиеМониторингаКонсьюмеров`

## Breaking относительно раннего пилота документов

Контракт контрагентов по ТЗ **несовместим** с решениями `pilot-bp-rf-exchange` по ряду пунктов (broadcast без `organization-id`, soft-delete ручных детей без `exchange_owned`, отсутствие `revision`, каталог ошибок, ожидание головы). Источник истины по контрагентам — этот релиз.

## Не входит в 1.0.0

- Адаптер документов (счета / реализации / поступления)
- Исходящие топики `from-1c.*`
- Публичный ACL prod (оформляется отдельно с командой Kafka)
